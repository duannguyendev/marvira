================================================================================
EVENT TAXONOMY (v1.0 — IMPLEMENT THESE)
================================================================================

  Naming: snake_case, stable. Do not rename after launch without a migration note.
  Params: only primitive strings/numbers; keep cardinality low (no free-text answers).

  ---------------------------------------------------------------------------
  A) App lifecycle
  ---------------------------------------------------------------------------
  [x] app_open
      When: app comes to foreground / cold start (dedupe per Firebase defaults OK)
      Params: optional — none required

  ---------------------------------------------------------------------------
  B) Hunt (core loop) — highest priority for growth
  ---------------------------------------------------------------------------
  [x] hunt_started
      When: user starts / joins playing an event
      Params: event_id (string)

  [x] place_unlocked
      When: GPS unlock succeeds for a place
      Params: event_id, place_id

  [x] place_answered
      When: user submits an answer at a place (success or fail)
      Params: event_id, place_id, correct (bool or 0/1)

  [x] hunt_completed
      When: user finishes the hunt / marks event complete
      Params: event_id, score (number, optional), duration_sec (optional)

  [x] hunt_abandoned
      When: user leaves mid-hunt if detectable (optional v1.0; nice-to-have)
      Params: event_id, places_done (number, optional)

  ---------------------------------------------------------------------------
  C) Practice
  ---------------------------------------------------------------------------
  [x] practice_opened
      When: Practice list or training screen opens
      Params: optional — source (list|training)

  [x] practice_answered
      When: user submits a practice answer
      Params: question_id, correct (0/1)

  ---------------------------------------------------------------------------
  D) Create / publish (supply side)
  ---------------------------------------------------------------------------
  [x] event_draft_created
      When: user creates a new event draft
      Params: none or event_id

  [x] event_published
      When: user publishes an event
      Params: event_id

  [ ] event_unpublished
      When: user unpublishes (useful later for cap analytics)
      Params: event_id
      Note: no unpublish UI yet — AnalyticsEvents.eventUnpublished helper ready

  ---------------------------------------------------------------------------
  E) Growth / invites
  ---------------------------------------------------------------------------
  [x] invite_opened
      When: app opens from invite / deep / universal link
      Params: event_id (if known), link_type (invite|share|other)

  [x] share_tapped
      When: user taps share after hunt or from event
      Params: event_id, surface (post_hunt|event_detail|other)

  ---------------------------------------------------------------------------
  F) Store / feedback (light)
  ---------------------------------------------------------------------------
  [ ] review_prompt_shown   (if you show in-app review)
  [ ] review_prompt_result  (optional: accepted|dismissed — if API allows)
  [x] feedback_submitted    (if user sends feedback from app)

       src/services/analytics.ts
