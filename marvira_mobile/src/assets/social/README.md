## Size rules we follow

- **Button height = 44pt** on iPhone and iPad (Apple recommended; equal prominence for Google/Facebook).
- **Apple:** use *Left-aligned* (not Logo-only) for “Continue with Apple” text buttons. Logo-only is only for icon-only controls.
- **Apple PNGs:** `@1x` 31×44, `@2x` 62×88, `@3x` 93×132 — covers iPhone 3x and iPad 2x. For other heights Apple requires SVG/PDF (we stay at 44pt).
- **Google:** multicolor “G” on white; do not recolor or stretch.
- **Facebook:** Primary “f” mark; crop to circle so the pack’s black canvas does not show.

Guidelines:

- https://developers.google.com/identity/branding-guidelines
- https://developer.apple.com/design/human-interface-guidelines/sign-in-with-apple
- https://developers.facebook.com/docs/facebook-login/userexperience/
