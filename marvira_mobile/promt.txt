CORE FEATURES
===================================

1️⃣ AUTHENTICATION
- User can Register / Login using SSO (OAuth-style flow)
- Store auth token securely
- Auth guard for protected screens

2️⃣ HOME / EVENTS LIST SCREEN
- Display list of events fetched from API
- Each event shows:
  - Title
  - Description
  - Distance from user (based on current location)
  - Status (Not Started / In Progress / Completed)
- Search and filter events based on:
  - Current user location
  - Distance radius
- Pull-to-refresh
- Beautiful modern UI (inspired by top Dribbble / Behance mobile designs)

3️⃣ EVENT DETAILS SCREEN
- Map at the top (Mapbox)
- Show:
  - User current location
  - All places for the event
  - Highlight current active place
- Event progress indicator
- List of places (locked/unlocked)

4️⃣ PLACE GAME FLOW
For each place in the event:
- Each place has:
  - Coordinates (lat/lng)
  - Question
  - Answer validation via API
- App must:
  - Detect when user is within 100 meters of the place
  - Only then unlock place details & question
  - Prevent skipping places
- User answers the question:
  - POST answer to API
  - If correct → unlock next place
  - If incorrect → show error and allow retry

5️⃣ EVENT COMPLETION
- When last place is completed:
  - Show completion screen
  - Celebration animation
  - Mark event as completed

6️⃣ USER PROFILE SCREEN
- Basic user information
- Completed events list
- Logout option
