HOW TO GET API URL / JWT / DB / REDIS (owner guide)
================================================================================
These are NOT bought from Apple/Google. They come from YOUR hosting setup.

1) PRODUCTION_API_URL (https://api.marvira.com)
   - Rent a VPS or PaaS (Railway, Fly.io, Render, AWS, DigitalOcean, etc.)
   - Deploy marvira_dashboard_api apps/api (see docs/deployment.md + Docker)
   - Point DNS: api.marvira.com → that service (Cloudflare or domain registrar)
   - Enable HTTPS (platform TLS or Cloudflare proxy)
   - Test: curl https://api.marvira.com/health

2) JWT_SECRET
   - Generate yourself (do not reuse demo secrets):
       # PowerShell
       -join ((48..57)+(65..90)+(97..122) | Get-Random -Count 48 | % {[char]$_})
       # or OpenSSL / any password manager “random 48 chars”
   - Put ONLY in API hosting env (never in the mobile app or git)
   - Must be ≥32 random characters

3) DATABASE_URL (PostgreSQL)
   - Create a managed Postgres (Neon, Supabase, Railway, AWS RDS, DigitalOcean, …)
   - Prefer PostGIS if available (optional; app can fall back)
   - Copy the connection string the provider shows, then add pool limit, e.g.:
       postgresql://USER:PASSWORD@HOST:5432/marvira?schema=public&connection_limit=20
   - After first deploy: prisma migrate deploy (entrypoint does this in Docker)

4) REDIS_URL
   - Create Redis (Upstash, Redis Cloud, Railway Redis, ElastiCache, …)
   - Copy URL, e.g. redis://default:PASSWORD@HOST:6379
   - Production MUST have Redis (do not set REDIS_DISABLED=true)

5) CORS_ORIGIN (once URLs exist)
   Example when all three are live:
     https://www.marvira.com,https://admin.marvira.com
   (add more origins if you use staging)

Suggested first deploy set for www.marvira.com:
  NEXT_PUBLIC_SITE_URL=https://www.marvira.com
  NEXT_PUBLIC_SUPPORT_EMAIL=support@marvira.com
  NEXT_PUBLIC_API_URL=https://api.marvira.com
  OAUTH_DEV_BYPASS=false
  JWT_SECRET=<generated>
  DATABASE_URL=<from Postgres provider>
  REDIS_URL=<from Redis provider>
  CORS_ORIGIN=https://www.marvira.com,https://admin.marvira.com
