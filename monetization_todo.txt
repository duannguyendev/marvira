DECISIONS SUMMARY (locked for planning)
================================================================================

ONE PRODUCT: Marvira Plus (subscription)
  - Do NOT sell separate “Organizer Pro” at launch — bundle into Plus
  - Free users: play everything + create/draft freely + up to 10 PUBLISHED events
  - Plus: no ads + unlimited published + badge + practice/share perks

PRICING (balanced — keep users, slight revenue; not set to match server bill)

  Launch default:
    Monthly  $3.99 / month
    Yearly   $29.99 / year   ← highlight on paywall (“best value”)

  Allowed to test later:
    Monthly  $4.99
    Yearly   $39.99

  Avoid at launch: $6.99+/mo, tiny “+5 publish” packs as main offer
  Regional store pricing OK (SEA can be lower)

FREE vs PLUS

  Free
    - Full hunts, leaderboards, basic practice
    - Create events + unlimited drafts
    - Up to 10 concurrent PUBLISHED events (unpublish frees a slot)
    - Hub banners + optional rewarded + rare post-session interstitial

  Plus ($3.99/mo or $29.99/yr)
    - Remove all ads
    - Unlimited published events
    - Plus badge (cosmetic)
    - Exclusive practice packs / daily challenge
    - Exclusive share / certificate themes
    - Optional later: early access to featured hunts

ADS (least annoying)

  Never during outdoor hunt (map / unlock / answer / between places)
  Banner: Home, Practice list, Profile, Favorites
  Practice = best ad surface (list banner + after round / session)
  Rewarded: cosmetics or extra practice set (NOT hints)
  Interstitial: only after hunt completed OR practice session ended (cooldown)

NOT monetized with hints
  Place hint is optional / often empty — never sell or reward “hints”

EXPECTATIONS (honest)

  Ops cost lean ~$80–200/mo; full prod ~$150–300/mo
  ~1,000 MAU → ads may partly cover hosting; not a salary
  ~25k–50k MAU + ads + Plus → shot at ~$3k/mo after tax
  Flappy Bird-level ad money needs viral millions + constant retries — not this genre
  Practice helps ad revenue more than outdoor hunts; still needs enough users

================================================================================
IMPORTANT PRODUCT CONSTRAINT
================================================================================

  Place “hint” is optional and often empty / low value.
  Do NOT use hints as the main rewarded-ad reward or Plus benefit.
  Monetize with: ad-free, cosmetics, practice perks, publish-slot unlock.

================================================================================
RECOMMENDED MODEL (read first)
================================================================================

Principle: Never sell or interrupt the core hunt loop.
  Core loop = find event → walk → GPS unlock → answer → next place → finish.
  That loop stays free and ad-free during play.

Hybrid:

  1) FREE forever
     - Join public / invite events, play full hunt, leaderboards, basic practice
     - Create + draft freely; max 10 concurrent PUBLISHED events

  2) ADS — practice-weighted, hunt-safe
     - Banner on hubs (especially Practice list)
     - After practice round / practice session end (stronger $ than hunt)
     - Rewarded: frame / extra practice set / post-hunt share theme
     - Optional interstitial after hunt OR practice session (cooldown)
     - Never on map, unlock, answer, active route

  3) IAP — Marvira Plus only at launch
     - $3.99/mo or $29.99/yr (yearly default highlight)
     - No ads + unlimited publish + badge + practice/share perks
     - Skip consumable packs at launch
     - B2B web billing later (schools/cities) — separate from consumer Plus

Do NOT do:
  - Monetize place hints
  - Pay to unlock places / skip GPS / buy leaderboard rank
  - Forced video while walking or before answering
  - Ads on map / navigation
  - Nickel-and-dime “+1 publish” as the main IAP
  - Block first publish or block drafts

PHASE M3 — PUBLISH LIMIT (bundled into Plus)
================================================================================

Decision:
  Free: 10 concurrent PUBLISHED events (unpublish frees a slot)
  Drafts: unlimited always (create never blocked by monetization)
  Plus: unlimited published
  Prefer concurrent cap over lifetime “10 ever”

  Before v1.3 (v1.0–v1.2): NO publish cap — create + publish freely.

  When cap turns on (v1.3) — grandfather over-cap creators:
    - Existing published events STAY live (do NOT force-unpublish or delete)
    - If free user already has >10 published: block NEW publishes only
    - They can still: create drafts, edit, unpublish, re-publish only if
      after unpublish count ≤10, OR subscribe to Plus
    - UX: “You have 15 published (Free allows 10). Unpublish some or go Plus
      to publish more. Your current hunts stay live.”
    - Do NOT grandfather “unlimited forever” for early users (keeps rules simple)

[ ] M3.1 Enforce publish cap in API + mobile create flow
[ ] M3.2 At cap UX: “Free: 10/10 published. Unpublish one or go Plus.”
[ ] M3.2b Over-cap grandfather UX (count >10 when flag flips)
[ ] M3.3 Show usage (e.g. 7/10 or 15/10 published) in My Events / Profile
[ ] M3.4 Anti-abuse rate limits / admin tools
[ ] M3.5 Later: B2B web plans for schools/cities (not required for consumer launch)
